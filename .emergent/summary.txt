<product_requirements>
The LuxePass app provides a premium mobile experience across Client, Admin, and Gym interfaces, secured by JWT, with token, client registration, gym management, and financial features. Initially, the focus was on fixing gym login failures, inconsistent API URLs, frontend navigation, and ensuring Tokens and Financial admin tabs worked, prioritizing payment systems (Stripe/Pagar.me), push notifications, and UX.

Later requirements included: for clients, daily supplementation logs, nutrition plans, functional Generate Workout, Visited Gyms, check-in with maps/location/notifications, and professional guidance (messaging, scheduling with availability); for admin, dedicated Nutritionist/Personal Trainer tabs (manage clients, schedules, plans), gym activation/deactivation, and a real-time Dashboard. A robust professional login, test premium client, interactive interfaces for plan creation, patient flagging, and accessible professional navigation were critical. Recent emphasis includes a comprehensive scheduling system with professional profiles, seamless client assignment and visibility, client check-in at nearest gym with token usage (1/day), Google Maps integration, upgrade paths for basic clients (Workout/Nutrition tabs showing plan info, full price, next month validity), interlinked professional/client schedules with 1-2 monthly consultations (depending on plan), a cancel appointment feature (re-scheduling next day), a Ver Planos button in financial section showing current plan and plan change data (requiring admin authorization), and real plan values.
</product_requirements>
